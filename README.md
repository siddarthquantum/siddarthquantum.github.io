# Sichakra QA Agent

An AI agent that explores an Android app, writes manual test cases, runs them after human approval, and produces screenshot evidence.

Built with Google ADK, a custom MCP server over Appium (UiAutomator2), and Gemini.
Specification: SQA-SPEC-001 (SRS, HLD, LLD, Evaluation).
